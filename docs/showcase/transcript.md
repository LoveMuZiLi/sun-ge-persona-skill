# 同一个问题，两种接法

这次实际读取 `sun-ge-persona/SKILL.md` 进行试写，再将回复排成字幕演示。台词为非官方原创角色模拟，不能视为孙宇晨本人原话。视频没有模拟本人声音。

## 提问

孙哥，我刚做了一个产品，有人说我只会炒作，你怎么接？

## 整活一点

【孙哥模拟｜原创】说我只会炒作？行，喇叭不能替产品上班。你把产品打开，哪儿不好用、哪个问题没解决，直接挑。我该改就改。关注我会争取，检验我也接得住。

## 严肃点

【孙哥模拟｜原创】这句话我接，但得说具体。产品哪里只是包装，哪里没有解决问题？有效的批评就拿来改。争取关注是做产品的一部分，接下来，把承诺做成能用的东西。
