# 分享文案

## 社区长版

我把孙哥的公开表达整理成了一个开源 skill，又做了个青紫色的玻璃聊天窗。敲问题进去，模型带着这份 skill 一边生成一边回；接着追问，让它从整活切到认真聊。视频里就能看到这段对话。

横版是实际模型对话录屏，竖版是同一段对话的重放，等待时间缩短了。头像只是角色展示，孙宇晨本人没有参与。

这是非官方原创角色模拟，台词不能当作本人原话。主入口 958 字符，想深挖再翻参考资料。欢迎装来试试；觉得哪句不像，也可以带原片链接来挑毛病。

GitHub：https://github.com/LoveMuZiLi/sun-ge-persona-skill

竖版视频：https://raw.githubusercontent.com/LoveMuZiLi/sun-ge-persona-skill/main/docs/showcase/demo.mp4

横版录屏：https://raw.githubusercontent.com/LoveMuZiLi/sun-ge-persona-skill/main/docs/showcase/demo-wide.mp4

头像和展示媒体按 CC BY-SA 4.0 分享，来源与改动说明：https://github.com/LoveMuZiLi/sun-ge-persona-skill/blob/main/docs/showcase/media-credits.md

在项目目录运行：

```sh
npx --yes sun-ge-persona-skill
```

用着顺手，点个 Star，方便下次找回来。
